① Importer et analyser un PDF

Les réponses déjà marquées dans le texte sont prioritaires. Les réponses proposées par l’IA sont identifiées et doivent être vérifiées, surtout en pharmacologie ou en santé.

Générer un questionnaire à partir du cours

Utilise le texte extrait ci-dessus. Les questions sont proposées par IA à partir du cours ; vérifie les réponses avant de les utiliser.

Formats : mélange QCM à réponse unique, QCM à réponses multiples et Vrai/Faux.
L’analyse locale reconnaît notamment les formats « ✓ Réponse correcte : VRAI/FAUX » et les options A–D précédées d’un ✓. Les PDF scannés nécessitent un OCR qui n’est pas inclus dans cette version.

Configuration IA

La clé API ne doit jamais être placée dans ce fichier HTML. Configure-la côté serveur dans un fichier .env. Si le serveur n’est pas démarré, l’import et l’analyse locale restent disponibles.

Endpoint : POST /api/answer-questions. La clé IA est conservée côté serveur dans AI_API_KEY. Cette version utilise par défaut l’API compatible Groq et son quota gratuit, sous réserve des limites du fournisseur.
CompoTest · Bêta privée · Les questionnaires et résultats sont synchronisés sur ton compte. L’IA peut se tromper : vérifie les réponses, en particulier pour les contenus médicaux.
